Projects

Question Answering tool with LLM

An intelligent question answering tool that combines Large Language Models with Google TAPAS, a transformer model designed for tables. It gives accurate, contextual answers to natural language queries about tabular datasets, bridging the gap between questions and complex data tables.

Recommendation system for investment in research projects

A recommendation system that identifies the best investors for each combination of research group and research subject. Deep learning models built with TensorFlow predict the most promising matches, PostgreSQL stores group, subject and investor data, and a FastAPI REST API connects the engine to user-facing applications.

Facial Expression Analysis tool

A convolutional neural network built with TensorFlow that classifies facial emotions such as happiness, sadness, anger, and surprise. A FastAPI REST API lets users upload images and receive real-time predictions, for use in marketing, gaming, and healthcare.

Mask Detection tool

An automation system that detects face masks in images and videos using TensorFlow and OpenCV. It handles multiple faces at once and classifies them by mask presence, so it can support public safety and compliance monitoring.

Service Price Recommendation system

A best-price recommendation system for computer services in Australia. Scrapy gathers pricing data from major market and sales companies, and TensorFlow models predict the best service price for the next day.

Old aged-care hospitalisation alarm system

Analysis of time-series data from sensors in home appliances to detect anomalies in daily behavior. Device signals become 24-character strings of hourly activity, and frequency metrics plus Levenshtein distance flag abnormal days without manual monitoring, enabling proactive healthcare. Predictive models are being optimised with Keras and TensorFlow (activation functions and dropout).

Breast Cancer Prediction

Prediction of breast cancer from features of digitized fine needle aspirate (FNA) images, using the Wisconsin Diagnostic Breast Cancer dataset (569 samples: 357 benign, 212 malignant; 30 features each). An optimized SVM improved diagnostic accuracy, reducing false negatives from 11 to 2.
